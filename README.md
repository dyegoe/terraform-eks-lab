# terraform-eks-lab

Terraform EKS Lab is a project to create a lab environment for learning EKS.

## Installation

### Requirements

- [Terraform](https://www.terraform.io/downloads.html) >= 1.4.6

### Setup

```bash
cd terraform/
terraform init
terraform apply
```
